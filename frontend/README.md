# FationHub Frontend

React + Vite frontend for the FationHub ecommerce project.

## Setup
```bash
npm install
npm run dev
```

## Environment
Create `frontend/.env`:

```env
VITE_API_URL=http://localhost:5001
```

## Scripts
- `npm run dev` start dev server
- `npm run build` production build
- `npm run lint` run ESLint

## Main Modules
- Public pages: home, products, product details, contact
- Auth pages: login, register
- User pages: cart, checkout, my orders, profile, returns
- Admin pages: dashboard, products, orders, users, offers, refunds, settings
